# Домашнее задание №2

## Описание
Программа считывает список студентов и их книг из JSON-файла (с использованием Jackson), а затем обрабатывает данные с помощью Stream API (peek, flatMap, sorted, distinct, filter, limit, map, findFirst).

## Требования
- Java 17+
- Maven

## Запуск
Запустить метод `main` в классе `ru.aston.hometask.Main`.
