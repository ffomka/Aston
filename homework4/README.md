# Homework 4: Многопоточность в Java

В этой папке представлены решения трех задач на многопоточность.

## 1. DeadlockExample.java
**Демонстрация взаимной блокировки (Deadlock).**
Два потока захватывают ресурсы в разном порядке (`lock1 -> lock2` и `lock2 -> lock1`). Из-за задержек `Thread.sleep(100)` возникает ситуация, когда каждый поток держит один ресурс и ждет второй, который занят другим потоком. Программа зависает навсегда.

**Как запустить:** Запустить метод `main`. Программа зависнет после вывода сообщений о захвате первых ресурсов. Остановить можно принудительно.

## 2. LivelockExample.java
**Демонстрация активной блокировки (Livelock).**
Два потока используют `ReentrantLock` и метод `tryLock()`. Если поток не может захватить второй ресурс, он отпускает первый и пытается снова. Из-за случайных задержек (`Math.random()`) потоки постоянно "уступают" друг другу, но ни один не может завершить работу. В отличие от Deadlock, потоки не заблокированы, а активно работают, но прогресса нет.

**Как запустить:** Запустить метод `main`. В консоли будет бесконечный цикл попыток захвата ресурсов. Остановить можно принудительно.

## 3. AlternatingPrinter.java
**Поочередный вывод "1" и "2".**
Два потока бесконечно выводят символы "1" и "2" по очереди, начиная с "1". Для синхронизации используется общий объект-монитор, методы `wait()` и `notifyAll()`, а также флаг `isFirstTurn`.

**Как запустить:** Запустить метод `main`. В консоль будет бесконечно выводиться `12121212...`. Остановить можно принудительно (Ctrl+C).
